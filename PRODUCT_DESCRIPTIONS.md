Copy the complete source description into `description`; set `preserve_description: true`. Preserve item lists, levels, counts, formatting, login/transfer conditions, compatibility, restrictions and limitations. Do not replace the description with a title-based summary or account-level/tier fields. Extra factual attributes may accompany the source body, but must not replace it. A short source description can remain short; never invent missing details.

Remove supplier personal/contact information, private account IDs, credentials, marketplace branding and supplier links. Retain legitimate license attribution. Use only Digital Racer's WhatsApp +923454342911 for ordering. Keep a private import report recording the source URL, full-description comparison and required removals.

When restoring a shortened existing description, verify the same supplier listing ID on the actual source page. Preserve its catalog identity, title, price, photos and canonical URL. Preserve useful existing factual detail alongside the full source description. Do not replace unrelated existing descriptions or remove disclosed transfer limitations.

Regenerate product pages after inventory changes and verify that the live description contains the entire cleaned source body, including its ending. Check the full body, not just a prefix or length.
